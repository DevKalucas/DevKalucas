### About

I'm an application developer in my apprenticeship, building cross-platform apps with **Flutter** and web apps with **React + TypeScript**. I like apps that feel fast and smooth, and I like turning a rough idea into something people can actually use.

- Currently learning: system design, testing, making apps feel faster
- Open to: collaborations and good conversations about code
- If I do something twice by hand, I build a tool for it

Got an app idea? Open an issue or just say hi.
